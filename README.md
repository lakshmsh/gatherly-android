# Gatherly

Gatherly is a cosmic-themed chat platform with a browser client, Express API, and Android application. It is designed around community-driven communication, server-based organization, and a space-inspired UI.

This repository combines:
- a modern web frontend
- a Node.js/Express backend
- an Android mobile app
- supporting documentation and validation notes

## Overview

Gatherly is inspired by Discord-style communication tools, but with a custom cosmic aesthetic and a broader multi-platform setup. The project includes:
- user authentication
- server creation and membership management
- channel-based community structure
- message sending and retrieval
- attachment support
- real-time sync patterns and polling-based updates
- responsive dark-mode UI design

## Features

- User registration and login
- Public/private-style server/community organization
- Channel-based conversations
- Message history and interaction flows
- Attachment and media support
- Status tracking and active user presence
- Modern UI using cosmic color themes and motion
- Android app support with Firebase and Kotlin tooling
